# 出山IT事務所｜GitHub Pages LP

出山IT事務所は、宮城県仙台市を拠点に、保護活動・小さな事業の「発信」「デザイン」「IT」を支える事務所です。

ホームページ制作、SNSの初期整備、ロゴや名刺のデザイン、里親募集・クラウドファンディング準備などを、AIも活用しながらお手伝いします。

- 公開ページ：[deyama-it.github.io](https://deyama-it.github.io/)
- 公式ホームページ：[www.deyama-it.com](https://www.deyama-it.com/)

## このLPについて

このリポジトリは、公式ホームページのトップページと事業案内をもとに作った、1ページ完結型のランディングページ（LP）です。

サービス内容、目安価格、お問い合わせ方法を1ページにまとめ、「まず何を頼めるのか」が短時間で伝わることを目指しています。

## 制作方針：Codexに全振りしています

このLPは、企画整理・構成案・HTML/CSS/JavaScriptの実装・デザイン調整を、AIコーディングエージェント **Codex** に全振りして制作しています。

ただし、公開する文章・価格・リンク・デザインは、出山IT事務所が最後に確認してから公開しています。AIに任せきりにせず、事業内容と異なる表現や誤った情報を出さないための最終確認は人が担当します。

### ページ構成

| エリア | 内容 |
| --- | --- |
| ヘッダー | 公式ホームページに寄せた赤基調のナビゲーション |
| ヒーロー | 出山IT事務所のビジョンと、支援する対象 |

### 使用技術・ファイルの役割

| 項目 | 内容 |
| --- | --- |
| 言語 | HTML / CSS / JavaScript |
| ホスティング | GitHub Pages |
| 公開処理 | GitHub Actions（`main` へのプッシュで実行） |

### ローカルで確認する方法

リポジトリ直下で、次のコマンドを実行します。

```powershell
python -m http.server 4175 --directory .
```

ブラウザで `http://127.0.0.1:4175/` を開くと確認できます。終了は、起動したPowerShellで `Ctrl + C` です。

## 今あるホームページを、1ページのLPにもできます

すでにホームページがある方も、その内容をもとに「サービス・価格・お問い合わせ」を1ページへ整理したLPを作れます。

- 情報が多くて、最初に何を見ればよいか伝わりにくい
- SNSプロフィールから飛んだ先を、分かりやすくしたい
- まずは小さく、依頼の入口だけ整えたい

そんなときに、既存サイトの文章や写真を活かしながら、必要な情報を絞ったページにします。制作はCodexに丸投げする形で進めつつ、内容と最終公開の確認は出山IT事務所が行います。

相談は、[X](https://x.com/deyama_it)・[note](https://note.com/deyama_it)・メール（contact@deyama-it.com）からどうぞ。
